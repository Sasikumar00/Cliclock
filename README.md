# Cliclock
A CLI based alarm clock built with python

## Functional Requirements
- Users should be able to create alarms with trigger time, custom tag and tune
- Users can see list of active and inactive alarms
- Users can update the metadata of existing alarms
- Users can delete an existing alarm

## Non Functional Requirements
- System should automatically trigger an alarm with sound
- System should be able to manage multiple alarms concurrently
